## 1. Key Factual Metrics

| Metric | Value | Description |
| :--- | :--- | :--- |
| **Expense Ratio (TER)** | 1.03% | Annual management fee percentage |
| **Exit Load** | Exit load of 1% if redeemed within 1 year | Penalty on early redemption |
| **Minimum SIP** | ₹100 | Minimum monthly SIP amount |
| **Minimum Lumpsum** | ₹100 | Minimum initial investment |
| **Riskometer** | Moderately High | Official SEBI risk classification |
| **Benchmark** | NIFTY 100 Total Return Index | Reference index benchmark |
| **Lock-in Period** | Nil (No lock-in period) | Statutory lock-in duration |
| **Fund Manager** | Prashant Jain | Portfolio manager |
| **Launch Date** | 01-Jan-2013 | Inception / launch date |
| **Stamp Duty** | 0.005% (from July 1st, 2020)% | Regulatory stamp duty |

## 2. Tax Implications & Notes
> If you redeem within one year, returns are taxed at 20%. If you redeem after one year, returns exceeding Rs 1.25 lakh in a financial year are taxed at 12.5%.
